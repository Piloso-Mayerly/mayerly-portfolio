Desarrollo web · IA

AI-Powered Routine Planner

Plataforma web orientada a mejorar la organización del tiempo de estudiantes mediante planificación inteligente, seguimiento de productividad y automatización.

  • Python
  • Django
  • JavaScript
  • Git

Mi contribución

02 / 03

Data science · Machine learning

Climate Change K-Means Analysis

Análisis de patrones de cambio de temperatura entre países mediante técnicas de aprendizaje no supervisado utilizando datos climáticos de FAO.

  • Python
  • Pandas
  • Scikit-learn
  • K-Means
  • PCA

Problema que resuelve

Los datos climáticos por país son extensos y difíciles de comparar a simple vista, por lo que se necesitaba agruparlos para identificar patrones similares.

Resultado

Segmentación de países según sus patrones de cambio de temperatura, incorporando preparación de datos, selección de variables, evaluación de clusters y visualización de resultados.

Ver repositorio ↗

03 / 03

Business intelligence · Data analytics

E-commerce Analytics

Solución de Business Intelligence para analizar el desempeño de ventas mediante un modelo dimensional y dashboards interactivos orientados a la toma de decisiones.

  • Power BI
  • PostgreSQL
  • Python
  • DAX
  • Power Query

Problema que resuelve

Los datos de ventas dispersos dificultan evaluar el desempeño del negocio; se requería un modelo centralizado y dashboards claros para decidir con información.

Desarrollo

Preparación y limpieza de datos, construcción de un modelo estrella en PostgreSQL, creación de medidas DAX y desarrollo de dashboards para análisis ejecutivo y evolución temporal.
